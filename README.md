# Smart Insurance Portal

## Overview
A full-stack insurance management application developed using Java Spring Boot and PostgreSQL with REST API integration and layered backend architecture.

---

## Features
- User Authentication
- Policy Management
- CRUD Operations
- REST APIs
- Database Integration

---

## Tech Stack
- Java
- Spring Boot
- PostgreSQL
- Hibernate/JPA
- HTML
- CSS
- JavaScript

---

## Architecture
Controller → Service → Repository → Database

---

## API Endpoints
POST /login  
GET /policies  
POST /add-policy  
DELETE /policy/{id}

---

## Future Improvements
- JWT Authentication
- Docker Deployment
- Cloud Hosting
